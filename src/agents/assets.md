# Asset Plan

## Asset Sources

- Use original product photography whenever possible.
- Use Unsplash or Pexels for temporary lifestyle and shop imagery.
- Use free commercial-use icons such as Lucide.
- Verify license and attribution requirements before publishing any external asset.

## Required Asset Categories

### Product Assets

- Tumbler product photos
- Product mockups from multiple angles
- Transparent product cutouts
- Print-area overlays and templates
- Product specification diagrams

### Brand Assets

- Logo and favicon
- Color palette
- Typography choices
- Social sharing image
- Email and dashboard icon set

### Website Assets

- Hero image
- Lifestyle images showing customized products
- Integration logos for supported marketplaces
- Simple workflow illustrations
- FAQ/help illustrations if needed

### Design Studio Assets

- Starter design templates
- Backgrounds and patterns
- Decorative shapes
- Basic icons and graphics
- Font list with appropriate licenses
- Product mockup files

## Asset Rules

- Prefer optimized WebP or AVIF for website images.
- Keep original design files separate from generated PNG/TIFF files.
- Store uploaded user artwork privately.
- Generate thumbnails for design-library browsing.
- Use descriptive filenames and stable asset IDs.
- Do not use copyrighted artwork, brand marks, or fonts without permission.

## Temporary Placeholder Policy

During prototyping, placeholders are acceptable, but product mockups and supplier specifications should be replaced with verified assets before launch.
